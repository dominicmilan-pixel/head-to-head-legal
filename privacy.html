Head to Head Privacy Policy

Last updated: October 12, 2026

Head to Head is a party game published by Olive Dating LLC. This policy describes version 1.0.

Accounts

The app does not ask you to create an account. It does not ask for your name, email address, phone number, contacts, photos, or location. It does not include advertising, analytics, or tracking.

Information stored on your phone

The app saves one setting on the device: whether countdown sounds are on or off. That setting stays on the phone and is not sent with catalog requests.

When a published deck downloads successfully, the app saves that deck’s cover and card photos in the app’s private storage so the deck can be played offline. Uninstalling the app removes the setting and the downloaded photos.

The sample decks shipped inside the app are already on the phone. Playing a game does not upload card photos, guesses, or the sound setting.

Requests the app makes

When the deck shelf opens, or when you pull to refresh it, the app requests the published deck list from Head to Head Studio:

GET https://head-to-head-studio.lovable.app/api/public/catalog

If a deck has been published, the app then requests that deck’s download description and the cover and card image files it names. Those image addresses are short-lived links hosted for the Studio storage. The app does not send an account token, a purchase token, or the countdown-sound setting with these requests.

The sample decks remain playable when the phone is offline or when a download does not finish.

What those requests expose

The app does not add a device identifier, advertising identifier, or account identifier to the request.

Serving the request still reveals the connection to the hosts that receive it. The catalog host answers through Cloudflare. Signed image files are served from the Studio storage host. The app’s own Studio code does not read the IP address, user agent, or device model from these requests, and it does not write them into the game database. There is no player table and no request log table in that database.

How long Cloudflare, the Studio host, or the storage host keep their own connection logs is not set in the Head to Head project, and this policy does not claim a retention period for those logs.

Permissions

Version 1.0 does not request access to the microphone, camera, photo library, contacts, location, or tracking.

The app plays short sounds and can keep the screen awake while a card is showing. Neither of those features sends information off the device.

Purchases

Version 1.0 does not sell decks and does not contact a payment provider.

Children

The game does not ask anyone, including children, to create an account or to enter personal information. The network requests described above can still occur when the deck shelf refreshes.

Changes

If a later version starts collecting personal information, this policy will be updated before that version is released.

Contact
